# Ralph Laurence D. Copre — Design Portfolio

A responsive portfolio website showcasing graphic design, logo making, and the ZYX visual identity project.

## View the site
Once GitHub Pages is enabled, the website will be available at:

https://rdcopre-max.github.io/ralph-portfolio/

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.
4. Wait for GitHub Pages to finish deploying.

## Theme
Dark navy, white, and blue accent `#5094FB`.
